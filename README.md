# 💻 Tech Store

E-commerce de produtos tecnológicos inspirado em grandes plataformas do segmento, como a KaBuM!, desenvolvido com HTML5, CSS3 e JavaScript puro.

A Tech Store é um projeto de e-commerce em desenvolvimento, criado com o objetivo de simular a experiência de compra em uma loja virtual de tecnologia.

A plataforma apresenta uma interface moderna, com foco na navegação, organização de produtos e experiência do usuário (UX).

Todo o desenvolvimento atual foi realizado utilizando tecnologias Front-End, incluindo a implementação de uma simulação de autenticação de usuários com JavaScript, sem integração com Back-End ou banco de dados até o momento.

### Funcionalidades

- **Página inicial:** apresentação da loja, ofertas e produtos em destaque.
- **Catálogo de produtos:** organização e exibição de produtos tecnológicos.
- **Carrinho de compras:** interação e gerenciamento de produtos selecionados.
- **Sistema de login:** simulação de cadastro e autenticação utilizando JavaScript.
- **Interface interativa:** manipulação dinâmica de elementos com JavaScript.
- **Navegação entre páginas:** experiência de navegação semelhante à de um e-commerce real.
- **Design responsivo:** adaptação da interface para diferentes dispositivos.
- **Experiência do usuário:** organização visual e navegação intuitiva.

### Status do projeto

**Em desenvolvimento.**

Novas funcionalidades e melhorias estão sendo implementadas continuamente.

### Próximas etapas

- Integração com Back-End.
- Implementação de banco de dados.
- Autenticação real de usuários.

### Objetivo

Desenvolver habilidades em Front-End, aplicando conceitos de HTML, CSS e JavaScript na construção de um e-commerce, explorando lógica de programação, manipulação do DOM, interatividade e experiência do usuário.

O projeto também serve como base para futuras implementações de Back-End e integração com banco de dados.
